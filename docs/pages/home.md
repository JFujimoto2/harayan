# トップページ

## URL
`/`

## 概要
画像中心のヒーローセクションで第一印象を与えるランディングページ

## セクション構成

### 1. ヒーローセクション
- フルスクリーンの背景画像
- オーバーレイテキスト（キャッチコピー）
- CTAボタン

### 2. コンセプトセクション
- ブランドメッセージ
- 簡潔な説明文

### 3. サービス紹介（カード形式）
- 店舗へのリンク
- 採用情報へのリンク

### 4. お知らせ（オプション）
- 最新情報の表示エリア

## デザイン要件
- 画像: ダミー画像（後で差し替え）
- レスポンシブ対応
- スムーズスクロール
