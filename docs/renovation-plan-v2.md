# Harayan サイト改修計画 v2

> ヒアリングシート(2026/01/25)に基づく改修計画

---

## 1. プロジェクト概要

### クライアント情報
| 項目 | 内容 |
|------|------|
| 業態 | 日本茶スタンド、和食・鉄板、カフェバー、卸売、EC |
| 店舗 | 八十八（浅草・渋谷・鎌倉）、A kyoto、B kyoto |
| ターゲット | 20〜40代の観光客（国内外） |
| 地域 | 東京・神奈川・京都（観光地中心） |

### サイトのゴール
| 優先度 | ゴール | 詳細 |
|--------|--------|------|
| **最優先** | 予約・採用・EC | すべて簡潔に導線を設計 |
| サブ | 企業の信頼 | コーポレートとしての信頼感 |

### 最重要価値
> **「光」**

---

## 2. デザイン方針

### 2.1 全体トーン
- **シンプルカジュアル**
- 20〜30代が「働きたい」と思えるデザイン
- 画像・動画で**わくわく感**を演出
- 「見たことある感」「Shopify感」を避ける

### 2.2 参考サイト分析

#### 好きなサイト（取り入れたい要素）
| サイト | 特徴 | 採用ポイント |
|--------|------|-------------|
| [komfyoverseas.com](https://www.komfyoverseas.com/) | ビニール×カクテル文化、洗練された都会感 | 画像ギャラリー、雰囲気重視 |
| [notahotel.com](https://notahotel.com/) | ラグジュアリーミニマリズム、余白の美学 | フルスクリーン画像、控えめアニメーション |
| [andsupply.store](https://www.andsupply.store/) | アーストーン、高級感×ミニマル | スクロールアニメーション、大判写真 |

#### 嫌いなサイト（避けるべき要素）
| サイト | 避ける理由 |
|--------|-----------|
| goodthingstore.tokyo | 見たことある感、Shopify感 |
| kbtkombucha.com | テンプレート感が強い |
| productoftime.co.jp | 人物写真が多すぎ、社長が前面に出すぎ |

### 2.3 カラー設計

```
【ベースカラー】
- ホワイト (#ffffff, #fafafa)
- ライトグレー (#f5f5f5)

【各店舗アクセントカラー】（後日確定）
- 八十八: 日本茶グリーン系？
- A kyoto: 和食・鉄板のイメージ？
- B kyoto: ジン・バーのイメージ？

【共通アクセント】
- ダークグレー (#1a1a1a) - テキスト・ボタン
- ミディアムグレー (#666666) - 補助テキスト
```

### 2.4 フォント
- 参考: [andsupply.co](https://andsupply.co/)
- **見出し**: Work Sans / Inter（洗練されたサンセリフ）
- **本文**: Noto Sans JP（日本語の可読性）
- **特徴**: 軽量、モダン、クリーン

### 2.5 画像・動画の使い方
- **フルスクリーン画像**を積極活用
- **動画背景**でわくわく感を演出
- 人物写真は控えめに（スタッフ集合写真等は避ける）
- 空間・商品・体験を重視

## 3. サイト構成（IA）

### 3.1 必要ページ一覧

#### Phase 1: すぐ必要
| ページ | 優先度 | 内容 |
|--------|--------|------|
| TOP | 必須 | ブランドイメージ、各店舗への導線 |
| About / Company | 必須 | 企業概要、理念、事業内容 |
| Stores（店舗一覧） | 必須 | 全店舗のハブページ |
| └ 八十八 | 必須 | 浅草・渋谷・鎌倉の3店舗 |
| └ A kyoto | 必須 | 和食・鉄板レストラン |
| └ B kyoto | 必須 | 日本茶×ジン カフェバー |
| Business | 必須 | 卸売、コンサル等の事業紹介 |
| Recruit | 必須 | 採用情報（20-30代向け） |
| Contact | 必須 | お問い合わせフォーム |

#### Phase 2: 後々必要
| ページ | 優先度 | 内容 |
|--------|--------|------|
| Reservation | 中 | 予約システム連携 |
| Shop (EC) | 中 | オンラインストア |
| News / Journal | 低 | お知らせ・ブログ |

### 3.2 サイトマップ（案）

```

├── About（企業情報）
│   ├── Philosophy（理念）
│   └── Business（事業内容）
├── Stores（店舗）
│   ├── 八十八
│   │   ├── Asakusa
│   │   ├── Shibuya
│   │   └── Kamakura
│   ├── A kyoto
│   └── B kyoto
├── Recruit（採用）
├── Contact（お問い合わせ）
└── [Phase 2]
    ├── Reservation
    └── Shop
```

## 7. 現状との差分

### 変更が必要な箇所
| 現状 | 変更後 |
|------|--------|
| 単一店舗構成 | **複数店舗対応**（八十八 × 3, A kyoto, B kyoto） |
| Shops = 1店舗 | **Stores** = 店舗ハブ + 各店舗詳細 |
| 事業内容なし | **Business** ページ追加 |
| シンプルな画像使用 | **フルスクリーン・動画**でわくわく感 |
| Instagram連携なし | **各店舗Instagram埋め込み** |

### 維持する箇所
- ホワイトベースのカラースキーム ✓
- シンプルカジュアルなトーン ✓
- Inter + Noto Sans JP フォント ✓
- モバイルファースト ✓
