# 店舗情報

## URL
`/shops`

## 概要
店舗の詳細情報を掲載するページ

## セクション構成

### 1. ページヘッダー
- タイトル「Shops」
- サブタイトル

### 2. 店舗カード（現在1店舗）
- 店舗画像
- 店舗名
- 住所
- 営業時間
- 定休日
- 電話番号
- Googleマップ埋め込み（オプション）

### 3. 複数店舗対応（将来拡張）
```erb
<!-- 複数店舗になった場合のコメントアウト例 -->
<%# @shops.each do |shop| %>
<%#   render 'shop_card', shop: shop %>
<%# end %>
```

## デザイン要件
- カード形式のレイアウト
- 店舗画像は大きめに表示
- 地図埋め込みスペース確保

## 拡張性
- 将来的に複数店舗に対応可能な構造
- 店舗データはビューに直接記述（DB無し）
