# 採用情報

## URL
`/recruit`

## 概要
求人情報を掲載するページ

## セクション構成

### 1. ページヘッダー
- タイトル「Recruit」
- サブタイトル（採用メッセージ）

### 2. 求める人物像
- 簡潔なメッセージ
- 働く魅力

### 3. 募集職種
- 職種名
- 仕事内容
- 応募資格
- 勤務地
- 勤務時間
- 給与
- 待遇・福利厚生

### 4. 応募方法
- 応募フロー説明
- コンタクトページへの誘導

## デザイン要件
- 読みやすい求人情報レイアウト
- 働く環境がイメージできる画像
- CTAボタン（応募へ誘導）
